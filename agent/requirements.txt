# Exact-pin google-adk so pip does not have to search its whole version
# history. fastapi/uvicorn/starlette/google-cloud-aiplatform/google-genai
# are left out on purpose: google-adk declares its own compatible ranges for
# all of them, and adding separate pins on top is what caused a resolver
# conflict (and a very slow backtracking search) earlier.
#
# Verified against PyPI on 2026-08-14: google-adk 2.7.0 requires
# fastapi>=0.133,<1, uvicorn>=0.34,<1, starlette>=1.3.1,<2,
# google-genai>=2.12.1,<3, google-cloud-aiplatform[agent-engines,evaluation]>=1.148.1,<2.
#
# Run `pip install -U google-adk[mcp]` before the hackathon submission to
# catch further drift - this library moves fast.
#
# The [mcp] extra is required, not optional: google-adk's MCP support (the
# whole reason this agent works) imports the separate `mcp` PyPI package
# (the official Model Context Protocol SDK, mcp>=1.24,<2), which is NOT
# installed by plain `google-adk` - confirmed by a real ModuleNotFoundError
# during a container build test, not assumed.
google-adk[mcp]==2.7.0
